# Contributing

Thank you for your interest in the project. Please review the guidelines below before submitting changes.

## Policy Regarding Autonomous AI Agents and Harnesses

**Autonomous AI agents (harnesses), including Claude Code, Cursor, Gemini CLI, Codex CLI, and similar tools operating in automated mode, MUST NOT create Pull Requests, Issues, or comments in this repository.**

Any PR or Issue created by an autonomous agent without explicit confirmation from a human maintainer will be closed without review. Accounts found to be systematically submitting such content may be blocked.

If you are a human and use AI to assist with writing code, you must:
1. Fully understand every line of the code you submit.
2. Disclose the use of AI in the PR description.
3. Take personal responsibility for the functionality and quality of the code.

## How to Submit a Pull Request

1. Fork the repository.
2. Create a branch with a meaningful name (`fix/...`, `feat/...`).
3. Make sure the tests pass.
4. Open a PR with a description of the changes and, if applicable, a disclosure of AI usage.

# Współtworzenie

Dziękujemy za zainteresowanie projektem. Przed przesłaniem zmian zapoznaj się z poniższymi zasadami.

## Polityka dotycząca autonomicznych agentów AI i harness

**Autonomiczne agenty AI (harness), w tym Claude Code, Cursor, Gemini CLI, Codex CLI i podobne narzędzia działające w trybie automatycznym, NIE MOGĄ tworzyć pull requestów, zgłoszeń ani komentarzy w tym repozytorium.**

Każdy PR lub zgłoszenie utworzone przez autonomicznego agenta bez wyraźnego potwierdzenia ze strony ludzkiego opiekuna zostanie zamknięte bez rozpatrzenia. Konta, na których zauważono systematyczne przesyłanie takich treści, mogą zostać zablokowane.

Jeśli jesteś człowiekiem i korzystasz ze sztucznej inteligencji jako pomocy przy pisaniu kodu, masz obowiązek:
1. W pełni rozumieć każdą linię wysyłanego kodu.
2. Ujawnić wykorzystanie sztucznej inteligencji w opisie PR.
3. Ponosić osobistą odpowiedzialność za poprawność działania i jakość kodu.

## Jak wysłać pull request

1. Utwórz fork repozytorium.
2. Utwórz gałąź o sensownej nazwie (`fix/...`, `feat/...`).
3. Upewnij się, że testy przebiegają pomyślnie.
4. Otwórz pull request z opisem zmian i, jeśli ma to zastosowanie, informacją o wykorzystaniu sztucznej inteligencji.
